# WebShare Pro v7.1

> 🌐 **웹 기반 파일 공유 서버 with PyQt6 GUI**

![Python](https://img.shields.io/badge/Python-3.8+-blue)
![Flask](https://img.shields.io/badge/Flask-Server-green)
![PyQt6](https://img.shields.io/badge/PyQt6-GUI-purple)
![License](https://img.shields.io/badge/License-MIT-yellow)

**WebShare Pro**는 파이썬으로 제작된 올인원 파일 공유 서버입니다. 웹 브라우저만 있으면 어디서든 파일을 공유하고 관리할 수 있습니다.

## ✨ 주요 기능

### 🔐 보안
| 기능 | 설명 |
|------|------|
| PBKDF2 암호화 | 비밀번호 솔트 기반 암호화 (구버전 호환) |
| CSRF 보호 | 모든 POST 요청에 토큰 검증 |
| IP 차단 | 5회 로그인 실패 시 15분 자동 차단 |
| 경로 탐색 차단 | `../` 등 상위 경로 접근 원천 차단 |
| AES-256 암호화 | 개별 파일 암호화/복호화 |

### 📂 파일 관리
- **파일 업로드/다운로드**: 드래그앤드롭, 폴더 업로드 지원
- **대용량 파일**: 청크 업로드로 10GB까지 지원
- **휴지통**: 실수로 삭제해도 복원 가능 (7일 자동 삭제)
- **버전 관리**: 파일 수정 시 자동 백업 (최대 5버전)
- **태그/메모**: 파일에 색상별 태그 및 메모 추가
- **ZIP 다운로드**: 폴더 통째로 압축 다운로드

### 🔗 공유 기능
- **임시 공유 링크**: 만료 시간 설정 (1~168시간)
- **비밀번호 보호**: 공유 링크에 비밀번호 설정
- **다운로드 제한**: 최대 다운로드 횟수 설정
- **QR 코드**: 모바일 기기로 빠른 접속

### 🎬 미디어
- **이미지 갤러리**: 슬라이드쇼 및 썸네일 보기
- **동영상 스트리밍**: HTTP Range 지원 (탐색 가능)
- **오디오 플레이어**: 폴더 내 음악 연속 재생
- **문서 미리보기**: Word, Excel, PowerPoint, CSV, JSON

### 👥 다중 사용자
- **역할 분리**: 관리자 / 게스트 권한
- **사용자 관리**: 개별 계정 생성 및 용량 제한
- **세션 모니터링**: 실시간 접속자 확인

## 📱 사용 방법

### 1. 서버 시작하기

1. `웹서버 프로그램v4.py` 실행
2. GUI 창에서 **"서버 시작"** 버튼 클릭
3. 표시되는 URL로 웹 브라우저에서 접속

![서버 GUI](https://via.placeholder.com/400x200?text=Server+GUI+Preview)

### 2. 웹 브라우저에서 접속

1. 브라우저에서 `http://서버IP:5000` 접속
2. 비밀번호 입력 (기본값: 관리자 `1234`, 게스트 `0000`)
3. 파일 탐색 및 관리 시작

### 3. 파일 업로드

**방법 1: 드래그앤드롭**
- 파일을 브라우저 화면에 끌어다 놓기

**방법 2: 업로드 버튼**
- 상단 업로드 버튼 클릭 → 파일 선택

**방법 3: 폴더 업로드**
- 폴더째로 드래그앤드롭 (하위 구조 유지)

### 4. 파일 공유하기

1. 파일/폴더 우클릭 → **"공유 링크"** 선택
2. 만료 시간 설정 (1~168시간)
3. (선택) 비밀번호 및 다운로드 횟수 제한 설정
4. **"링크 생성"** 클릭
5. 생성된 링크 복사하여 공유

### 5. 파일 암호화

1. 파일 우클릭 → **"암호화"** 선택
2. 암호 입력 후 확인
3. 파일이 `.enc` 확장자로 암호화됨
4. 복호화 시 동일 암호 입력 필요

## 💡 활용 예시

### 🏠 가정용 NAS 대용
```
집에서 WebShare Pro를 실행하고, 외출 시 스마트폰으로
사진, 동영상, 문서에 접근하세요.

설정 예시:
- 공유 폴더: D:\가족사진
- 포트: 5000
- 관리자 비밀번호: 강력한 비밀번호 설정
```

### 🏢 사무실 파일 공유
```
부서 내 파일 공유 서버로 활용하세요.

설정 예시:
- 공유 폴더: \\서버\공유폴더
- 게스트 업로드 허용: ON
- 일일 다운로드 제한: 100회
```

### 📚 온라인 수업 자료 배포
```
학생들에게 강의 자료를 배포하세요.

설정 예시:
- 공유 링크로 자료 전달
- 다운로드 횟수 제한으로 유출 방지
- 비밀번호로 수강생만 접근
```

### 🎉 행사 사진 공유
```
결혼식, 여행 등 사진을 참석자와 공유하세요.

활용법:
1. 사진 폴더 공유 링크 생성
2. QR 코드로 현장에서 바로 접속
3. 갤러리 모드로 슬라이드쇼 감상
```

### 💼 고객에게 대용량 파일 전달
```
이메일로 보낼 수 없는 대용량 파일을 전달하세요.

활용법:
1. 파일 업로드 후 공유 링크 생성
2. 비밀번호 설정
3. 만료 시간: 24시간
4. 다운로드 제한: 3회
```

## 🔧 설정 옵션

### GUI 설정 (시스템 트레이)
- **공유 폴더**: 공유할 루트 폴더 선택
- **포트**: 서버 포트 (기본: 5000)
- **관리자/게스트 비밀번호**: 접속 비밀번호
- **게스트 업로드 허용**: 게스트도 파일 업로드 가능
- **HTTPS 사용**: 암호화된 연결 (자체 서명 인증서)
- **시작 시 자동 실행**: Windows 시작 시 자동 실행

### 고급 설정 (webshare_config.json)
```json
{
    "session_timeout": 30,       // 세션 만료 시간 (분)
    "daily_download_limit": 0,   // 일일 다운로드 횟수 제한 (0=무제한)
    "daily_bandwidth_limit_mb": 0, // 일일 대역폭 제한 (0=무제한)
    "disk_warning_threshold": 90,  // 디스크 경고 임계값 (%)
    "ip_whitelist": [],          // IP 화이트리스트 (빈 배열=모두 허용)
    "trash_auto_delete_days": 7  // 휴지통 자동 삭제 일수
}
```

## ❓ FAQ

### Q: 외부에서 접속이 안 됩니다.
**A:** 다음을 확인하세요:
1. 방화벽에서 해당 포트(기본 5000) 허용
2. 공유기 사용 시 포트 포워딩 설정
3. 호스트를 `0.0.0.0`으로 설정

### Q: 비밀번호를 잊어버렸습니다.
**A:** `webshare_config.json` 파일을 메모장으로 열어 `admin_pw` 값을 수정하세요.

### Q: 대용량 파일 업로드가 안 됩니다.
**A:** 100MB 이상 파일은 자동으로 청크 업로드됩니다. 브라우저를 새로고침하지 마세요.

### Q: 동영상 재생이 끊깁니다.
**A:** 네트워크 속도를 확인하세요. 로컬 네트워크 사용을 권장합니다.

### Q: 한글 파일명이 깨집니다.
**A:** v7.1에서 한글 파일명을 완벽 지원합니다. 최신 버전인지 확인하세요.

### Q: PyQt6이 없으면 실행이 안 되나요?
**A:** Tkinter로 자동 대체됩니다 (일부 기능 제한).
